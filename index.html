GOOGLEFLIGHTS

Build Google Flights search links where each leg gets its own cabin. Runs entirely offline — no request is made to Google unless you open a link.

Step 1 · Itinerary

Legs

One row per travel direction. Give each leg its own cabin — that is the part Google's own UI cannot do.

Step 2 · Travellers & filters

1

The passenger stepper adds to the selected traveller type. Google allows at most 9 travellers. Airline field takes an IATA code (BA) or an alliance name (ONEWORLD, STAR_ALLIANCE, SKYTEAM).

Tools

Paste any tfs token (or a full Google Flights URL) to see what it actually asks for.

Save a Google Flights one-way or round-trip results page (Right-click → Save as → HTML Only) and paste it here. The reader pulls the itineraries out of the page's ds:1 blob and matches them against a per-leg cabin vector. Multi-city pages carry no rows to read — Google loads those client-side.

Paste the JSON of one parsed itinerary (or a list of them) to get a booking deep link for that exact set of flights. Shape: {"legs":[{"from":"JFK","to":"LHR","departure":"2026-12-01T20:30","airline":"BA","flightNumber":"178"}]}
